# 政治概念地图

一个中文政治概念科普入口，用价值测评、议题地图和概念库帮助访客理解公共讨论中的价值取舍。

## 功能

- 40 道本地计算的价值测评题，生成五维结果和阅读线索。
- 五组价值坐标说明，帮助理解结果中的主要倾向和价值组合。
- 公共议题地图，把住房、教育、平台治理等现实问题连接到价值轴。
- 政治概念库，整理常见政治词条和容易混淆的概念对照。
- 阅读指南，提供测评前、测评后和直接查内容三种阅读路径；议题案例与词条来源可展开阅读。

## 本地使用

这是一个单文件静态页面，不需要安装依赖或启动构建工具。

直接用浏览器打开 `index.html` 即可使用。

## 隐私说明

测评答案只在浏览器本地计算，不上传服务器，不接入追踪代码。作答进度会自动保存在本机浏览器；提交后清除保存的作答进度，保留上次结果分数和生成时间。重新测试或清除站点数据可清除这些本地记录。浏览器限制存储时仍可完成测评，但无法保证刷新后恢复。
